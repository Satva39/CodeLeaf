CodeLeaf — Phase 3A: Learner Progress & Resume Flow
=================================================

Scope
-----
This increment improves the current learner loop without changing the database schema:
- Home page resumes the most recently recorded, available lesson (rather than merely opening a course root).
- Completed last lessons are labelled as review, not incorrectly described as unfinished.
- Draft/roadmap or empty courses cannot become public resume targets.
- A new learner gets a truthful “Start learning” path instead of the interface implying historical progress.
- Progress numbers show Loading/Unavailable rather than misleading zeros while account statistics are being fetched or cannot be verified.
- The progress page no longer displays HTML as an “in progress” course when no lessons have actually been completed.
- A recent lesson offers a course-scoped practice link.
- New styles are imported by their pages only. Global `frontend/src/styles.css` and its existing imports are not replaced or edited.

No backend files, DB schema, migrations, `.env` files, or production records are changed by this patch.

Apply (PowerShell)
------------------
Run from the parent directory containing `Code_Leaf` and this ZIP. Back up files first:

```powershell
$projectRoot = (Resolve-Path .\Code_Leaf).Path
$backupRoot = Join-Path (Get-Location).Path 'Code_Leaf_Phase3A_Backup'
$modifiedFiles = @(
  'frontend/src/pages/HomePage.jsx',
  'frontend/src/pages/ProgressPage.jsx'
)
foreach ($relative in $modifiedFiles) {
  $source = Join-Path $projectRoot $relative
  if (-not (Test-Path -LiteralPath $source)) { throw "Expected file is missing: $relative" }
  $backupFile = Join-Path $backupRoot $relative
  New-Item -ItemType Directory -Force -Path (Split-Path $backupFile) | Out-Null
  Copy-Item -LiteralPath $source -Destination $backupFile -Force
}
Expand-Archive -LiteralPath .\CodeLeaf_Phase3_Learning_Loop_Patch.zip -DestinationPath $projectRoot -Force
```

If you have edited either page locally, compare it with the patch first and merge the changes instead of overwriting them. The added files are:
- `frontend/src/lib/learningPath.js`
- `frontend/src/styles/phase3-learning-loop.css`
- `frontend/scripts/test_learning_path.mjs`
- `docs/PHASE3_LEARNING_LOOP.md`
