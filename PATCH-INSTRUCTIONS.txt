CodeLeaf Phase 2 — Course and Content Consistency
=================================================

This is a focused patch for the existing Code_Leaf repository. It preserves the
React + JavaScript/JSX + Vite frontend, FastAPI API, PostgreSQL database, and
Vercel/Render deployment. It does not change production data or environment
variables.

Before applying
---------------
1. Open PowerShell in the folder that contains Code_Leaf.
2. Run `git status --short`. Commit or back up any unrelated uncommitted edits.
3. This patch updates shared components/pages. It does not edit `frontend/src/styles.css`.
   Existing imports such as phase5.css and ui-polish.css are left untouched.
4. Extract this ZIP into the existing project root (the parent folder of
   `frontend/` and `backend/`), preserving paths. Allow files in the list above
   to be replaced only after backing up any local changes to those same files.

What changes
------------
- Tutorials course overviews show audience, prerequisites, outcomes, and a
  collapsible course outline in separate sections, with Start Learning visible
  near the top.
- References explicitly opt out of tutorial-only details; Projects and Practice
  rely on the shared component's safe compact default and do not load the outline.
- Reference pages get a common enriched layout across every course and a
  full-width detail panel. Authored descriptions/examples are preserved.
- Related lesson links come from the selected course's outline. External source
  links are restricted to HTTP/HTTPS schemes.
- Existing course filtering remains API-authoritative; roadmap/draft/empty
  course metadata does not become published merely because a page loads.

Validation
----------
From `frontend/`, run:

node scripts/test_phase2_content_consistency.mjs
node scripts/test_reference_details.mjs
node scripts/test_course_catalog_filters.mjs
node scripts/test_course_overview_cta.mjs
npm run build

Manual smoke checks:
- `/courses/html`: Start Learning is near the top; course-fit cards and outline
  appear before “Explore this course”.
- `/reference/html/<entry>` and `/reference/angular/<entry>`: shared detail
  structure; full-width outer panel; related links lead to lessons from that
  course.
- `/projects/html` and `/practice/html`: tutorial-only detail cards and outline
  are not displayed.
- Test mobile width and keyboard activation for the outline disclosure buttons.
