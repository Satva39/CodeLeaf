# Production-Ready E-commerce Interface — Starter

This starter uses plain HTML, CSS and JavaScript with Tailwind CSS v4 through the Vite plugin and Vite 7. No TypeScript is used. Use Node.js 20.19+ or 22.12+ for this Vite generation.

## Run locally (Windows PowerShell)

```powershell
npm install
npm run dev
```

Use the local URL printed by Vite. Confirm the installed Tailwind version before using v4-specific syntax in an existing project. Run `npm run build` after editing.

## Goal

Build and document a cohesive e-commerce frontend prototype. The capstone focuses on interface engineering, not a complete payment or backend system.

## Required features

- Responsive homepage with header, hero, categories and featured products
- Product listing, badges, filtering and product detail layout
- Cart and checkout interface with accessible forms and validation presentation
- Customer account, order history and status displays
- Light/dark themes, reusable tokens, custom utilities and component variants
- Responsive testing, production build, accessibility audit and visual-regression checklist

## Quality check

- Inspect narrow, medium and wide viewports.
- Use keyboard navigation and keep focus visible.
- Confirm the production CSS was generated.
- Add automated or human-reviewed tests where appropriate.
