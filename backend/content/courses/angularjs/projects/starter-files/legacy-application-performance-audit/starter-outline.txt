PROJECT: Legacy Application Performance Audit

Objective: Measure and improve an existing app through dependency inventory, watcher/render investigation, large-list optimization, API review, leak checks and regressions.
Required topics: Digest cycle, watchers, caching, browser developer tools, profiling, testing, and code quality.

Suggested structure:
- app entry/module declaration
- components/controllers for UI state
- services for reusable data access
- templates and route configuration where needed
- test plan with normal, edge, failure and cleanup cases

Implementation note: this text file is a planning starter rather than executable code. Create the application files in a local workspace and record your exact AngularJS version.
