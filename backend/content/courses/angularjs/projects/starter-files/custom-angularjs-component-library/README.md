# Custom AngularJS Component Library

## Objective
Create reusable inputs, buttons, validation helpers and confirmation components with documented contracts, consistent states and tests.

## Version and safety boundary
This is a legacy AngularJS 1.x learning project. Confirm the app's actual dependency version before running it. Use mock data or a local test API; do not place credentials or access-control rules in client code.

## Build milestones
1. Create the smallest route/component/view that expresses the required behavior.
2. Put reusable data or API logic behind a service.
3. Add loading, empty and failure states for asynchronous features.
4. Test normal cases, boundary cases, authorization assumptions, keyboard access and cleanup.
5. Record known limitations, setup steps and a modernization decision.

## Local verification
- Run the repository's existing build/test commands.
- Serve the browser application over HTTP using its pinned dependencies.
- Verify each route directly and refresh deep links.
- Record test outputs and any environment-specific limitations.
