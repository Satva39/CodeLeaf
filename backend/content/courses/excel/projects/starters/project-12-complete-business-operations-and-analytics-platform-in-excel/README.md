# Complete Business Operations and Analytics Platform in Excel

**Status:** draft starter. This directory provides the project brief and links to synthetic CSV data, not a finished `.xlsx` workbook.

## Objective
Develop a maintainable solution that consolidates operational records, analyzes performance, forecasts outcomes and presents results through an interactive dashboard.

## Suggested starter data
- Course-root path `assets/data/sales-transactions.csv` — synthetic transaction rows.
- Course-root path `assets/data/products.csv` — synthetic product and stock values.
- Course-root path `assets/data/customers.csv` — synthetic customer register.
- Course-root path `assets/data/students-marks.csv` — synthetic marks for student-result projects.
- Course-root path `assets/data/expenses.csv` — synthetic expense rows.

## Required features
- Structured sample sales, products, inventory, customers and transactions
- Power Query preparation and refresh
- Reliable lookups, business rules and exception checks
- Data Model/measures if supported
- Interactive dashboard and scenario forecasting
- Optional VBA or Office Scripts automation
- Quality assurance and professional delivery

## Required test evidence
1. Record formulas/transformations and input assumptions.
2. Independently calculate at least two outputs and compare with the workbook.
3. Test one blank/missing/duplicate/boundary case.
4. Check keyboard access, descriptive headings, meaningful chart labels, and readability.
5. Save a test copy; document Excel version, refresh instructions, limitations, and recovery steps.

The CodeLeaf platform currently checks submitted exercise text only; it does not execute Excel or ingest `.xlsx` files. This project needs human review of the actual workbook and evidence before it can be accepted.
