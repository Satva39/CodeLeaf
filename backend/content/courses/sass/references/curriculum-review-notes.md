# Sass curriculum review notes

- **Primary source:** `Sass.pdf`, 46 pages, inspected by text extraction and page-render contact sheets. Sections A–G were reviewed; the numbered curriculum in Section B contains 19 modules and all lesson numbers 1–169 with no gaps. The PDF is an outline rather than a library of lesson-length explanations or teaching diagrams.
- **Preserved coverage:** all 19 modules, 169 lesson titles, and their numbered subtopics are reproduced in `references/syllabus-index.json` and implemented as separate lesson files. All 25 practical exercises, 11 project briefs, five optional specialist tracks, and seven-stage learning path are represented in CodeLeaf-native form.
- **Modernization:** the course focuses on Dart Sass, `@use`, `@forward`, and namespaced `sass:` built-in modules. The legacy `@import` and legacy global-function patterns remain only in history/migration contexts. Official Sass documentation records `@import` deprecation beginning in Dart Sass 1.80.0; it is not presented as the default for new code.
- **Division:** lessons distinguish slash separators used by modern CSS from Sass arithmetic and teach `math.div()` for explicit division where appropriate.
- **Runtime boundary:** Sass is compiled to CSS. Media queries, CSS custom properties, supported modern CSS functions, focus states, and browser layout continue to be evaluated by the browser. Examples are marked `static-validation`; CodeLeaf's current playground does not compile Sass in-browser.
- **Version evidence:** Sass official documentation was checked on 2026-10-17. The official site displayed Dart Sass 1.105.2 during verification. Use the actual project-local version in `npx sass --version`; this course does not pin a package dependency because it imports as content, not as a new toolchain.
- **Estimated workload:** 75 hours is a CodeLeaf planning estimate, not a time estimate stated by the PDF. Learners can use the seven-stage roadmap and optional specialist tracks.
- **Visuals:** the PDF contains mainly text-based syllabus and project outlines rather than reusable instructional diagrams. The patch includes original, text-alternative-labeled SVG teaching diagrams: one overview per module and one per numbered lesson.
- **Assessment protection:** each lesson has three draft knowledge-check questions. Answers are in the server-side question files consumed by the existing knowledge-check endpoint, which filters answer keys from learner responses. Exercise solutions and project reference outlines are separate repository-only files; they are not embedded in exercise prompts/starter code.
- **Status:** all generated content is marked `draft`. The repository validator checks structure, paths, stable IDs, links, supported grader modes, visual assets, question shape, and rubric totals. Human Sass review, compiling representative examples, browser/accessibility testing, and content publication are still required. The current generated project briefs are scaffolds/assessment criteria, not claims that fully finished websites have been created.
