# Data Science course — curriculum review notes

- **Source:** `Data Science.pdf`, 55 pages, reviewed as page text plus a visual contact sheet of all pages. The document includes overview, complete curriculum, practical exercises, projects, specialist topics, learning path, and coverage checklist.
- **Retained coverage:** 24 modules and 258 consecutively numbered lesson headings from Section B are preserved in their source order. The visible PDF text was parsed for the original lesson titles and subtopics; each lesson stores `source_syllabus_number` and `subtopics`.
- **Practice work:** Section C's 26 practical exercises are represented in separate exercise files, linked to relevant lessons. Section D's 13 named projects plus end-to-end capstone are represented as 14 separate project briefs, with separate repository-only reference outlines and starter READMEs.
- **Specialist material:** Section E's advanced statistics, causal analysis, applied ML, deep learning, NLP, computer vision, time series, data engineering, MLOps, geospatial/graph/recommender/decision/research computing directions and optional tools are tracked in `references/specialist-tracks.json` and relevant modules.
- **Learning roadmap:** Section F's six phases and prerequisite relationships are represented in the roadmap visual and track map.
- **Corrections/exclusions:** No numbered lesson was intentionally removed. The PDF's general recommendations are treated as a curriculum scope, not as guaranteed current API signatures. Current version-sensitive code and platform-specific instructions must be checked against official docs before publication. No tool-specific library is made a hard prerequisite unless the PDF says so.
- **Technical caution:** This package is draft authored content. It is not a replacement for subject-matter review, live API testing, statistical review, legal review, or security review. Static Python/SQL examples are not run by the CodeLeaf browser. SQL blocks are query simulations unless a learner runs them against an approved local schema.
- **Source citations:** `references/reference-index.json` lists official documentation entry points for Python, JupyterLab, NumPy, pandas, SciPy, statsmodels, Matplotlib, Seaborn, PostgreSQL, scikit-learn, PyTorch, TensorFlow, Spark, Airflow, MLflow, FastAPI, Git, NIST AI RMF / Privacy Framework, and OWASP ML security. Verify the live documentation before implementation; URLs/API details can change.
- **Assets:** Original course/module/lesson diagrams are included as SVGs with alt text and captions in `assets/asset-manifest.json`. CSVs are wholly synthetic and documented at `assets/data/README.md`.
