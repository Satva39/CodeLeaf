# Probability Distribution Calculator — starter scaffold

Explore common probability distributions through reproducible calculations and clear interpretation.

## Setup

Create a virtual environment and install dependencies:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install numpy scipy pytest
```

## Start here

Implement the milestones in order. The sample values are synthetic. Keep input validation, numerical computation, tests, and reporting separate. Record `scipy.__version__`, units, tolerance choices, and any method limitations.

Run tests from this folder with `python -m pytest -q`. The initial tests define expected interfaces and may need expanding as features are added.

**Status:** starter scaffold, not a completed or publication-reviewed solution.
