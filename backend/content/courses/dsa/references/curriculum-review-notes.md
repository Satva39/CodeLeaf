# DSA curriculum review notes

- **Scope source:** `DSA(1).pdf`, 35 pages. The text layer was extracted and the rendered pages were visually reviewed in a contact sheet; the curriculum tables and project sections were also inspected.
- **Source curriculum:** 27 modules and 148 consecutively numbered lessons. All lesson titles and their listed subtopics are retained in the matching lesson JSON. Section C includes 55 exercise briefs; Section D includes nine projects plus one capstone; Section E has five optional specialization tracks; Section F gives six roadmap phases.
- **Corrections/exclusions:** No numbered syllabus lesson or source exercise title was intentionally omitted. The source's generic curriculum references to university course structures are retained as scope context, while official links are separately listed in `reference-index.json`. Where source items are broad, the generated explanations remain introductory rather than claiming every specialist algorithm is fully proved or implemented.
- **Language scope:** DSA is language-independent. The examples use Python 3.12+ as one inspectable implementation language and are marked `static-validation`; they are not run in the CodeLeaf browser or FastAPI server. Learners may translate them to another language.
- **Content status:** All lessons, exercises, projects, questions, and course metadata are **draft**. Generated content scaffolds, quiz distractors, exercise mappings, example correctness, and complexity explanations need subject-matter and instructional review before publishing.
- **Security:** No arbitrary-code execution runner is introduced. The lesson runner must not pass learner code through FastAPI's main process. Exercise graders use only the existing `choice`, `exact_text`, and `contains_all` static modes and are explicitly described as smoke checks; they do not certify algorithm correctness.
- **Gamification:** No lesson/exercise XP overrides are present. Existing server-side platform rules remain authoritative. This patch does not change reward, certificate, streak, or leaderboard logic.
- **Reference checks:** MIT OCW, Princeton Algorithms booksite, Python data-structure docs, `heapq`, `collections`, `bisect`, `unittest`, and `timeit` documentation URLs are included as starting references. They should be rechecked during human review and when lesson versions are pinned.
