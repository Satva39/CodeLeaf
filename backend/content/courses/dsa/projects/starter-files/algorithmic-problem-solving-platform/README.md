# Algorithmic Problem-Solving Platform

## Goal
Build an offline programming-practice platform that organizes problems, evaluates solutions, and illustrates performance.

## Scope milestones
1. Problem catalogue by topic and difficulty
2. Test-case runner using local isolated process only
3. Expected-output and edge-case tests
4. Reference implementations and complexity notes
5. Trace output, timing and memory where available
6. Search, filtering, progress and bookmarks
7. Report comparing baseline and improved algorithms

## Evidence required
- State input/output contracts and constraints.
- Include normal, edge and invalid-case tests.
- Explain the key invariant/correctness argument.
- Report time and auxiliary-space complexity.
- Record Python version, commands and observed output.
- Do not run untrusted learner code in a web-server process.

## Local setup
Use Python 3.12+ in a local virtual environment. Replace the starter stub, then run `python -m unittest -v`. A green result from the unimplemented starter is not a completion claim.
