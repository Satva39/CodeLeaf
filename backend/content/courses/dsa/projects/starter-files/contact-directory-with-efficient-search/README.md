# Contact Directory With Efficient Search

## Goal
Manage contacts while comparing data structures for storage and retrieval.

## Scope milestones
1. Add, update, delete, and search contacts
2. Exact and prefix search
3. Duplicate detection and sorting
4. Lookup performance measurements
