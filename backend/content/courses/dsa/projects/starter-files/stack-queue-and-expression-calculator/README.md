# Stack, Queue, and Expression Calculator

## Goal
Implement foundational linear structures and use them to evaluate expressions.

## Scope milestones
1. Stack and queue operations
2. Balanced-bracket validation
3. Expression conversion and postfix evaluation
4. Invalid-input handling

## Evidence required
- State input/output contracts and constraints.
- Include normal, edge and invalid-case tests.
- Explain the key invariant/correctness argument.
- Report time and auxiliary-space complexity.
- Record Python version, commands and observed output.
- Do not run untrusted learner code in a web-server process.

## Local setup
Use Python 3.12+ in a local virtual environment. Replace the starter stub, then run `python -m unittest -v`. A green result from the unimplemented starter is not a completion claim.
