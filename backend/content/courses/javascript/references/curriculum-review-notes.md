# JavaScript curriculum review notes

- **Source inspected:** `JavaScript.pdf`, all 56 pages, including the curriculum overview, complete 27-module outline, 36 practical exercises, 13 projects (including the productivity capstone), optional advanced/specialized areas, learning roadmap, and quality-check section.
- **Source coverage preserved:** all 302 uniquely numbered lesson topics (1–302) are preserved in `syllabus-map.json` and mapped to individual draft lessons. All 36 source exercises and 13 source projects are represented as separate files. The course contains 312 lessons after adding 10 supplemental bridge lessons.
- **Supplemental material:** the source syllabus lists exercises using `if...else`, conditional statements, and loops but does not provide a clearly dedicated numbered topic group for conditional statements, `switch`, the common loop forms, and loop-control flow. A 10-lesson `Control Flow and Loops` module was inserted after the operator module and before strings/arrays. This fills a prerequisite gap rather than excluding any source content. Original source topic numbers remain in each lesson's `source_syllabus_number`.
- **Standards/version correction:** the PDF notes an evolving 2027 ECMAScript draft. Stable lessons here are anchored to the fixed **ECMAScript 2026** edition. Proposals and new runtime APIs must be separately labeled and rechecked against support in target runtimes before publication; an evolving draft is not treated as an adopted stable feature.
- **Environment distinction preserved:** the DOM, Fetch API, and Node.js APIs are presented as host-environment APIs, not as ECMAScript language features.
- **No source topics intentionally excluded.** Some specialist subjects in Section E are retained as optional context/roadmap notes but not inflated into fictitious numbered lessons beyond the 302 source lesson topics.
- **Generated content caution:** the PDF is an outline, not a manuscript. Lesson prose, exercise scaffolds, project briefs and knowledge checks are original expansions and remain **draft**. They require technical/editorial review, execution of examples, and additional behavioral test coverage before publication.
- **Assessment limitations:** exercise configs use a supported token-based `contains_all` grading mode as a placeholder-compatible first-pass. Token grading alone cannot establish program correctness; reviewers should add behavior tests or select human review for appropriate exercises. The final exam blueprint/question bank are content files, not an implemented exam/session or certificate system.
- **Code execution:** examples are labeled `static-validation` and include local run instructions. No arbitrary user-code sandbox is introduced or implied; do not run learner code inside the FastAPI application process.
- **Official sources checked on 2026-10-11:** MDN JavaScript Guide/Reference, Ecma International ECMAScript 2026 specification, MDN host API guides, and the official Node.js release information and test runner docs. See `references/reference-index.json`.
