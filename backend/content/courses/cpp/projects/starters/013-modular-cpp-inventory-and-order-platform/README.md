# Modular C++ Inventory and Order Platform — starter files

This is a learning scaffold, not a finished product. It uses standard C++20 and contains no external package dependencies.

## Build

From this directory, run `g++ -std=c++20 -Wall -Wextra -Wpedantic main.cpp -o starter` (on Windows the output may be named `starter.exe`). Run it only after reviewing the code and build output.

## First milestones

- Read the project brief at `../../013-modular-cpp-inventory-and-order-platform.json` and keep the brief's acceptance criteria as your checklist.
- Add focused tests for ordinary, boundary, invalid-input, and failure cases.
- Separate core rules from input/output and storage as the project grows.
- Create separate domain, repository, service, CLI, and test layers before adding production-quality flows.

## Scope notes

This starter provides a baseline and intentionally leaves required features for the learner to implement. Review dependencies, portability, data validation, and persistence choices before publication. Do not use it with real personal or financial data.
