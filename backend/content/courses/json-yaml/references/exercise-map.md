## Grading boundaries

The existing CodeLeaf grader supports `choice`, `exact_text`, and `contains_all`. This course uses `contains_all` for a transparent text-presence smoke check; it does not execute JSON/YAML parsers, JSON Schema validators, shell commands, or general-purpose code. Project and exercise correctness therefore requires the referenced tool/version, valid/invalid/boundary evidence, and human review.
