# Library Management System

## Goal

Build a small Django application that demonstrates the required features while keeping configuration, models, views, templates, and tests organized.

## Setup assumptions

- Python and Django versions must match the course's official compatibility notes.
- Use a disposable local database and synthetic records.
- Read the project milestones, acceptance criteria, and official references before implementing.

## Suggested first steps

1. Create an isolated virtual environment and a Django project/app.
2. Write a short data model/URL sketch before adding views.
3. Add one automated success test and one denied/invalid case.
4. Document expected output, how to reset local sample data, and what was not tested.

## Safety and delivery

Do not commit secret values, customer information, payment credentials, or production database snapshots. Treat all uploaded data as untrusted. Do not deploy this starter as production-ready.
