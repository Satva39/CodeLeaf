- **Primary source:** the attached `Python.pdf`, 23 pages, prepared October 10, 2026. It defines 27 ordered modules, lessons 1–324, 28 practical exercises, 14 progressively difficult projects plus a capstone, optional specialist tracks, a seven-stage roadmap, and a coverage checklist.
- **Coverage:** all 324 numbered core lesson titles are preserved as separately addressable lesson JSON files. PDF subtopic lists are carried into lessons where present; major practice exercises and all listed projects have standalone files.
- **Python version statement:** the PDF states Python 3.15.0 was released on October 9, 2026. This was checked against the official [Python 3.15.0 release page](https://www.python.org/downloads/release/python-3150/) and [What's New in Python 3.15](https://docs.python.org/3.15/whatsnew/3.15.html) on October 11, 2026. Python 3.15-only subjects remain explicitly version-specific; verify syntax and third-party compatibility before use.
- **Scope notes:** the PDF presents a broad curriculum blueprint rather than full lesson prose. Lesson explanations, examples, assessments, and project briefs in this patch are draft expansions and must receive subject-matter review before publication. Specialist frameworks are treated as optional paths instead of claiming this course replaces their full specialist curricula.
- **Execution boundary:** the current CodeLeaf lesson editor displays stored example output and does not run Python. Python examples use `static-validation`; students must run examples locally. Production learner-code execution would require a separately deployed isolated runner with process/container isolation, wall-clock and CPU/memory limits, filesystem policy, network restrictions, and safe output handling.
- **Assessment boundary:** knowledge-check answer keys are in separate repository-only draft files; the current file importer does not create a live exam runner from these files. Review endpoint authorization before making any question bank public.
- **Gamification:** no course-authored XP override is included. The CodeLeaf importer/backend retain responsibility for XP awards and idempotency.
- **Schema/database:** this patch follows the existing file importer and does not require a database migration. Course stays in `draft` state.
- **Source references:** official versioned Python tutorial, language library documentation, Python Packaging User Guide, asyncio reference, security warning documentation, and PEP index are listed in `reference-index.json`. References were checked on 2026-10-11.
