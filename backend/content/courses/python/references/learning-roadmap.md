# Python learning stages (Section F of Python.pdf)

1. **Get started — Modules 1–5 (lessons 1–46).** Milestone: write basic programs without copying a complete solution.
2. **Solve problems — Modules 6–10 (lessons 47–112).** Milestone: complete beginner projects independently.
3. **Build larger programs — Modules 11–16 (lessons 113–188).** Milestone: build reusable components and persistent-data applications.
4. **Write reliable code — Modules 17–20 (lessons 189–240).** Milestone: deliver a tested project with documented dependencies.
5. **Build real applications — Modules 21–24 (lessons 241–287).** Milestone: complete an integration or application project.
6. **Choose a specialization — Module 25 (lessons 288–303).** Milestone: build a focused project using relevant external libraries.
7. **Prepare for professional work — Modules 26–27 (lessons 304–324).** Milestone: deliver a documented, tested, maintainable final project.

Recommended prerequisite relationships from the PDF: functions follow variables, data types and control flow; packages follow modules; OOP follows functions and collections; iterators follow loops, functions and collections; decorators follow functions, scope and classes; type hints follow functions and collections; testing follows functions, modules and exceptions; packaging follows packages and dependency management; API/database work follows functions, structured data, exceptions and file formats; async follows functions, coroutines and networking; optimization follows working code, testing and algorithmic reasoning; security follows validation, files, APIs and dependency management.
