# Personal Expense Tracker — CLI — starter files

This starter intentionally contains only a safe, minimal skeleton. Implement the project milestones in small steps.

## Requirements

- Swift reference toolchain: 6.4; verify your installed toolchain with `swift --version`.
- CodeLeaf's browser preview does not execute Swift. Compile/run command-line work locally; SwiftUI and Apple-framework work requires the relevant Apple SDK.
- Do not store private API credentials in the repository. Use environment configuration or a platform-appropriate secret store.
- Add automated tests for business rules, validation and boundary cases.

## Suggested workflow

1. Read the project brief and rubric.
2. Identify the core data model and acceptance criteria.
3. Implement one milestone at a time.
4. Run `swift test` if using a Swift package, or `swift main.swift` for a standalone command-line file.
5. Record platform assumptions, test evidence, limitations and next steps.
