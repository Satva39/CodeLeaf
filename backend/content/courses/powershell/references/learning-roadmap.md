# PowerShell learning roadmap (draft)

1. **Start (Modules 1–4, lessons 1–37):** understand the shell, install a current edition, discover commands, and navigate safely.
2. **Core model (Modules 5–9, lessons 38–95):** objects, pipeline operations, types, expressions, strings and control flow.
3. **Reusable scripts (Modules 10–12, lessons 96–133):** script interfaces, advanced functions, diagnostics and debugging.
4. **Data and platforms (Modules 13–15, lessons 134–167):** files, Windows inventory and cross-platform operation.
5. **Professional integration (Modules 16–20, lessons 168–212):** modules, APIs, remoting, .NET and secure automation.
6. **Quality and delivery (Modules 21–24, lessons 213–264):** tests, analyzer, performance, desired state, Git and CI/CD.
7. **Specialization and review (Modules 25–26, lessons 265–286):** enterprise tracks, compatibility, troubleshooting and final assessment.

Prerequisites follow the numbered lesson order. System changes, real tenants, remote hosts and external APIs are not required for the core practice tasks; use synthetic fixtures first. All content is draft.
