# Express.js visual asset checklist

All visual files in this course are original SVG diagrams. Dimensions are 1200×400 for module overview diagrams and 1200×420 for lesson concept flows. Each file has title/description metadata, visible text labels, alt text and a caption recorded in `asset-manifest.json`. Every listed visual is included locally; no remote image URLs, raster illustrations, or PDF thumbnails are dependencies.
